# Seven7een — صفحة الحسابات ورمز QR

- **الرابط المباشر:** https://deepblueit.github.io/s7/
- **رمز QR والبطاقة:** https://deepblueit.github.io/s7/qr.html
- **النشر:** يُنشر الموقع من فرع `gh-pages`؛ أي تعديل يجب أن يصل إلى هذا الفرع حتى يظهر على الرابط.

## محتوى المجلد
- `index.html` — صفحة الحسابات التي تُفتح عند مسح الرمز (تيك توك، إنستغرام، فيسبوك).
- `qr.html` — يولّد رمز QR تلقائيًا من رابط الموقع نفسه، مع بطاقة A6 جاهزة للطباعة وتحميل الرمز PNG أو SVG.
- `.nojekyll` — ملف فارغ يلزم GitHub Pages، اتركه كما هو.

لا يحتاج الموقع إلى أي إعداد أو بناء، ويعمل على أي استضافة أو رابط مؤقت لأن كل المسارات نسبية.

## الرفع على GitHub Pages (رابط مجاني مؤقت)
1. أنشئ مستودعًا عامًا جديدًا على GitHub، ثم ارفع الملفات كما هي من Add file ← Upload files.
2. من Settings ← Pages اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
3. بعد دقيقة تقريبًا يعمل الموقع على: `https://اسم-المستخدم.github.io/اسم-المستودع/`
4. افتح `qr.html` من الرابط نفسه، وسيظهر الرمز الصحيح جاهزًا للطباعة أو التحميل.

بديل أسرع: اسحب المجلد كاملًا إلى app.netlify.com/drop لتحصل على رابط فورًا، ثم افتح `qr.html` منه.

## تعديلات شائعة
- **تغيير الروابط:** عدّل قيم `href` الثلاث داخل `index.html`.
- **تغيير الشعار:** الشعار الحالي مؤقت (رقم 17 داخل إطار ذهبي). ضع `logo.png` بجوار `index.html` واستبدل عنصر الشعار بالسطر الموضّح في التعليق داخل الملف.

## ملاحظة مهمة
الرمز يحمل الرابط الذي رُفع عليه الموقع. إذا تغيّر الرابط لاحقًا (مثل الانتقال إلى دومين)، افتح `qr.html` من الرابط الجديد واطبع رمزًا جديدًا، أو أبقِ الرابط القديم يعمل حتى لا تتعطل البطاقات المطبوعة.
