# Seven7een Cafe — المنيو وصفحة الحسابات ورمز QR

- **الرابط المباشر:** https://deepblueit.github.io/s7/
- **المنيو:** https://deepblueit.github.io/s7/menu.html
- **رمز QR وبطاقة الطاولة:** https://deepblueit.github.io/s7/qr.html
- **النشر:** يُنشر الموقع من فرع `gh-pages`؛ أي تعديل يجب أن يصل إلى هذا الفرع حتى يظهر على الرابط.

## محتوى المستودع
- `index.html` — الصفحة التي تُفتح عند مسح الرمز: زر المنيو، ثم تيك توك وإنستغرام وفيسبوك.
- `menu.html` — المنيو كاملًا: صفحات الكتالوج كصور خفيفة، مع أزرار للأقسام وزر لتحميل نسخة PDF.
- `menu/` — صور صفحات المنيو `p01.jpg` حتى `p14.jpg`، وملف `seven7een-menu.pdf` (نسخة مضغوطة من الكتالوج).
- `qr.html` — يولّد رمز QR تلقائيًا من رابط الموقع، مع بطاقة طاولة A6 جاهزة للطباعة وتحميل الرمز PNG أو SVG.
- `assets/logo.webp` — شعار المقهى بخلفية شفافة.
- `.nojekyll` — ملف فارغ يلزم GitHub Pages، اتركه كما هو.

## تعديلات شائعة
- **تحديث المنيو:** استبدل صور `menu/` بالأسماء نفسها وبنفس عدد الصفحات، وحدّث ملف PDF. إذا تغيّر عدد الصفحات أو الأقسام فعدّل القائمة داخل `menu.html`.
- **تغيير روابط الحسابات:** عدّل قيم `href` داخل `index.html`.

## ملاحظة مهمة
الرمز يحمل رابط الموقع. تحديث المنيو أو الصفحة لا يغيّر الرمز، فالبطاقات المطبوعة تظل صالحة. أما إذا تغيّر الرابط نفسه (مثل الانتقال إلى دومين)، فافتح `qr.html` من الرابط الجديد واطبع رمزًا جديدًا، أو أبقِ الرابط القديم يعمل.
